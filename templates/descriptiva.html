Fórmulas aplicadas

Desarrollo analítico de las medidas y probabilidades del módulo.

LaTeX

\[ \bar{x} = \frac{\sum_{i=1}^{m} f_i x_i}{N} \qquad s^2 = \frac{\sum f_i x_i^2 - \frac{(\sum f_i x_i)^2}{N}}{N-1} \]

Con \(N = 50\), \(\sum f_i x_i = 280\) y \(\sum f_i x_i^2 = 1.808\), se obtiene \(\bar{x} = 5{,}60\) y \(s^2 = 4{,}898\).

\[ Q_k = L_{i-1} + \left(\frac{kN/4 - F_{i-1}}{f_i}\right) \cdot C \qquad IQR = Q_3 - Q_1 \]

\(Q_1 = 3{,}93\), \(Q_2 = 5{,}56\), \(Q_3 = 6{,}94\) y \(IQR = 3{,}01\) noches.

\[ P(A \cap B) = \frac{n_{AB}}{N} \qquad P(B \mid A) = \frac{P(A \cap B)}{P(A)} \]

\(P(A \cap B) = 15/100 = 0{,}15\) y \(P(B \mid A) = 0{,}15 / 0{,}17 = 0{,}8824\).

Los cálculos se realizan sobre la submuestra de control de 50 registros para las medidas descriptivas y sobre los 100 microdatos para la tabla de contingencia.
